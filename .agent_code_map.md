## Backend (`backend/`)

### Environment
- `backend/.env`: Active environment variables (gitignored — contains secrets).
- `backend/.env.example`: Template with all required configuration keys and comments.

### Core & Models (`backend/app/models/` & `backend/app/db/`)
- `db/session.py`: Async SQLAlchemy engine factory, SSL-required for Supabase Cloud PostgreSQL.
- `db/types.py`: `GUID` TypeDecorator (maps native Postgres UUIDs / SQLite `CHAR(36)`).
- `db/sqlite_shim.py`: SQLite monkey-patching for `postgresql.UUID` and `pgvector.Vector`.
- `models/user.py`, `workspace.py`, `paper.py`, `question.py`, `answer.py`, `answer_evidence.py`, `retrieved_evidence.py`: Persistence schemas supporting user ownership and paper Q&A history.
- `models/enums.py`: Enumerations for `PaperStatus`, `PipelineStage`, `SectionType`, `QuestionType`, and `RetrievalMode`.

### Services (`backend/app/services/`)
- `semantic_scholar_service.py`: NEW — Fetches related academic papers via Semantic Scholar Graph API with automatic CrossRef REST API fallback when rate-limited (429).
- `pipeline_orchestrator.py`: 5-stage async paper analysis pipeline (Extract → Structure → Chunk → Embed → Analyze).
- `pdf_extractor.py`: PyMuPDF text extraction with NUL byte sanitization for PostgreSQL UTF-8 compliance.
- `embedding_service.py`: OpenAI-compatible text embeddings with pgvector storage.
- `answer_generation_service.py`: 15-step grounded QA pipeline with `user_id` context, saves questions + grounded answers.
- `offline_ai.py`: Extractive summarizer with offline fallbacks for when Gemini is unavailable.
- `retrieval_service.py`: Hybrid semantic + section-aware + BM25 retrieval.
- `chunking_engine.py`: Structure-aware document chunking.
- `section_detector.py`: Scientific paper section classification.

### AI Providers (`backend/app/ai/`)
- `gemini_provider.py`: Multi-key rotation (`PL_01`–`PL_04`) and model fallback cascade (`gemini-flash-latest` → `gemini-3.5-flash` → `gemini-2.5-flash-preview` → `gemini-2.5-flash-lite`).
- `local_provider.py`: Ollama local model provider for offline inference.
- `router.py`: Routes LLM calls between Gemini and local provider based on availability.

### Schemas (`backend/app/schemas/`)
- `paper.py`: Includes `RecommendedPaper` and `PaperRecommendationsResponse` for Semantic Scholar API responses.
- `question.py`: `SourceMetadataItem` for evidence citation metadata.
- `answer.py`, `analysis.py`, `methodology.py`, `contribution.py`, `evaluation.py`, `evidence.py`, `retrieval.py`.

### API Routes (`backend/app/api/routes/`)
- `auth.py`: JWT login, registration, and hybrid OAuth endpoints. Auto-provisions default workspace.
- `papers.py`:
  - `POST /papers/upload`: Validated PDF upload → background pipeline.
  - `GET /papers/{paper_id}/status`: Real-time pipeline status polling.
  - `GET /papers/recommendations/search?title=...`: NEW — Search related papers by title (Semantic Scholar + CrossRef fallback).
  - `GET /papers/{paper_id}/recommendations`: NEW — Recommendations for an existing indexed paper.
  - `GET /papers/{paper_id}/chat-history`: Persisted Q&A history for re-login restoration.
  - `GET /papers/{paper_id}/analysis`, `/methodology`, `/contributions`, `/evaluate`.

### Database Migrations (`backend/alembic/`)
- `alembic/env.py`: Alembic migration environment, percent-encoding safe for Supabase PostgreSQL URLs.
- Current head: `002_add_oauth_and_admin_fields` (16 tables created on Supabase).

## Frontend (`frontend/`)

### Environment
- `frontend/.env` / `frontend/.env.local`: Active environment variables (gitignored — contains Supabase keys).
- `frontend/.env.example`: NEW — Template with VITE_API_URL and Supabase configuration.

### API Client
- `src/lib/api.ts`: Centralized API client with:
  - Auth: `loginUser`, `registerUser`, `logoutUser`, `oauthLogin`
  - Papers: `getPaper`, `getPapers`, `uploadPaper`, `deletePaper`, `retryPaperPipeline`, `reanalyzePaper`
  - Analysis: `getPaperAnalysis`, `getPaperMethodology`, `getPaperContributions`, `evaluatePaperBenchmark`
  - Q&A: `askPaperQuestion`, `getPaperChatHistory`
  - Recommendations: NEW — `getPaperRecommendations(paperId)`, `searchPaperRecommendations(title)`

### Routes / Pages
- `src/routes/paper.$id.tsx`: Paper detail view with:
  - Q&A chat history hydrated from Supabase on load.
  - 3-way RAG Evaluation Benchmark modal.
  - **NEW**: Related Research Papers section with title, authors, year, abstract, DOI links.
- `src/routes/papers.tsx`: Library view with search, filter, and delete.
- `src/routes/upload.tsx`: PDF drag-and-drop upload with real-time pipeline progress polling.
- `src/routes/index.tsx`, `settings.tsx`, `activity.tsx`: Dashboard, settings, and activity feed.

### Components
- `src/components/app/AppShell.tsx`, `Sidebar.tsx`, `TopBar.tsx`: Responsive workspace navigation.
- `src/components/app/AuthModal.tsx`: Hybrid auth modal (Google/Microsoft OAuth + Email/Password).
- `src/components/app/UploadZone.tsx`: Drag-and-drop PDF upload interface.
- `src/components/app/SectionCard.tsx`: Reusable editorial section container.
- `src/components/app/StatusBadge.tsx`: Processing status badge component.
- `src/components/app/PdfReader.tsx`: In-app PDF viewer.
- `src/components/app/EmptyState.tsx`: Empty state with optional `actionLabel` + `onAction` button.
- `src/components/app/states/ConfirmDialog.tsx`: Alert dialog with optional `tone` prop (`danger`, `warning`, `neutral`).
- `src/components/app/states/StatePanels.tsx`: `StatePanel`, `ErrorState`, `EmptyState`, `NetworkErrorState`, `SuccessState`, `ProcessingState`.
