# Project Architecture Map

## paperlens-atlas (Production Monorepo & Authoritative Master Documentation Suite)

Production-oriented monorepo & master specification layout:

```
paperlens-atlas/
├── README.md             # Master project introduction & document directory
├── docs/                 # Authoritative Master Documentation Suite
│   ├── PRODUCT_SPEC.md   # Product identity, philosophy, features, target users, scope boundaries
│   ├── ARCHITECTURE.md   # Monorepo layout, frontend/backend architecture, processing pipeline, RAG engine, DB schema
│   ├── RESEARCH.md       # Research novelty, generic RAG failure modes, experimental hypotheses, long-term vision
│   ├── DATASET.md        # Benchmark dataset schema, JSON annotation format, difficulty taxonomy, provenance
│   ├── EVALUATION.md     # 3-way RAG comparison, metric formulas (Recall@K, Precision@K, MRR, Grounding, Abstention)
│   ├── API.md            # FastAPI REST API endpoint reference
│   ├── SECURITY.md       # JWT auth, workspace isolation, PDF validation, PDF prompt injection defense
│   └── DEVELOPMENT.md   # Monorepo setup commands, testing instructions, agentic development rules
├── frontend/             # Lovable/Vite React Application
├── backend/              # FastAPI Async AI Backend Engine
├── .lovable/             # Lovable template metadata
├── docker-compose.yml    # Root Docker Compose orchestrator
├── AGENTS.md             # Agentic IDE instructions
├── .agent_code_map.md    # Agent long-term memory map
└── .agent_journal.json   # Agent short-term memory journal
```
