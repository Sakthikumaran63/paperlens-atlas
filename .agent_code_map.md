## Backend (`backend/`)

### Core & Models (`backend/app/models/` & `backend/app/db/`)
- `db/types.py`: `GUID` TypeDecorator (Maps native Postgres UUIDs / SQLite `CHAR(36)`).
- `db/sqlite_shim.py`: SQLite monkey-patching for `postgresql.UUID` and `pgvector.Vector`.
- `models/enums.py`: Enumerations for `PaperStatus`, `PipelineStage`, `SectionType`, `QuestionType`, and `RetrievalMode`.

### Services (`backend/app/services/`)
- `pipeline_orchestrator.py`: 5-stage async paper analysis pipeline (`EXTRACTING` $\rightarrow$ `STRUCTURING` $\rightarrow$ `CHUNKING` $\rightarrow$ `EMBEDDING` $\rightarrow$ `ANALYZING`).
- `offline_ai.py`: Deterministic pseudo-embeddings (`generate_offline_embedding`) & extractive summarizer (`generate_offline_summary`).
- `embedding_service.py`: Generates text embeddings with automatic offline fallback when unconfigured.

### API Routes (`backend/app/api/routes/`)
- `auth.py`: JWT login, registration, and hybrid OAuth endpoints.
- `papers.py`: Paper upload, status polling, background processing, retrieval, and QA.

### Scripts & Tests (`backend/scripts/` & `backend/tests/`)
- `scripts/ingest_qasper_benchmark.py`: Converts QASper dataset into evaluation format.
- `tests/test_auth.py`, `tests/test_paper_upload.py`, `tests/test_pipeline_orchestrator.py`: Unit and integration test suites.

---

## Frontend (`frontend/`)

- `src/components/app/AuthModal.tsx`: Hybrid authentication modal (Google/Microsoft OAuth + Email/Password toggle).
- `src/components/app/UploadZone.tsx`: Drag-and-drop PDF paper upload interface.
- `src/components/app/Sidebar.tsx` & `TopBar.tsx`: Responsive workspace navigation shell.
